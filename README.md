# hxwl-10 考古探方记录

跨探方地层关系校核台：在各探方独立编号地层的基础上，校核接界处高程与遗迹单位跨方归层。

## 技术栈

React 19 + Vite + TypeScript + 纯 CSS（无后端，状态在前端 reducer 中演示）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5110

## 功能规则

- **各自编号**：每个探方保留自己的地层编号与顶/底高程，接界通过「关联」把两侧本地编号对上号，不做全局统一编号。
- **2cm 阈值**：接界线两侧高程差 > 2 cm 自动进入待复核；复核员更新边界后，原观测保留留痕，统计、摘要、单位状态立即重算。
- **一个单位**：跨接界的遗迹单位在两个探方各留观察点，但始终是同一个单位，不拆成两个。单位状态按跨方地层连通图判定：已校核 / 待复核（路径含超差接界）/ 错层风险（归层互不连通）。
- **归属保留**：观察点归层修正只追加修正记录；出土物始终归属原观察点，不随修正移动。
- **领队确认制**：已确认地层锁定，现场只能补观察；附高程建议时生成新修订，领队批准后才改值，改前自动留存高程快照。
- **断网合并**：断网探方的观察先进本机批次（草稿→封口）；回网后按批回传，按观察点 ID 幂等合并，重复上传只算一次；失败批次单独重试，不影响其他批次。

## 角色

- 发掘队员：补现场观察与观察点、批次封口/回传（锁定层只能生成修订提案）
- 复核员：更新未锁定地层高程、更新接界边界、修正观察点归层
- 领队：确认地层、批准或驳回修订

## 代码结构

- `src/types.ts` 领域模型与 action
- `src/engine.ts` 纯计算：高差判定、跨探方地层连通图、单位状态、统计
- `src/store.ts` reducer：权限闸门、修订流程、断网暂存与幂等合并
- `src/seed.ts` 示例数据（含待复核接界、错层单位、断网暂存与失败批次）
- `src/components/` 各校核面板
