# hxwl-10 跨探方地层关系校核台

遗址相邻探方各自编号地层时，接界高程校核、跨方遗迹单位归层、确认层修订与断网观察合并的演示工作台。

## 技术栈

React + Vite + TypeScript + CSS（无后端，状态由 `useReducer` 管理）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5110

## 校核规则（均已固化在状态机中）

- **各编各号**：每个探方保留自己的地层编号、土色与顶底高程，不强行统一层号。
- **接界挂联**：探方接界只关联两侧对应地层；接界线高程差 **> 2cm** 自动进入待复核。
- **遗迹单位不拆**：跨接界的遗迹单位在两个探方各留观察点，但同属一个单位 id；
  观察点归层与接界关联对不上时单位置「疑似归错层」，接界待复核算「等待接界复核」。
- **复核留档**：复核员更新边界高程/换挂地层后，高差、统计指标、单位状态、摘要立即重算；
  原观察与出土物归属始终保留，归层只追加「有效归层」。
- **确认层走修订**：领队确认的地层现场不能直接改，只能补观察并生成修订；领队采纳后才改高程并重算。
- **断网合并**：断网期间观察按观察点本机暂存，回网后按批合并进原单位；
  按 `clientId` 幂等（重复上传只算一次）；失败批次单独重试，不影响其他批次。

## 代码结构

- `src/model.ts`：领域模型与派生计算（接界状态、单位状态、统计）
- `src/data.ts`：演示档案（3 探方、2 条接界，含 1 条超差、1 处疑似归错层）
- `src/store.tsx`：reducer 状态机（权限、修订、离线批次、幂等合并）
- `src/components/`：地层簿 / 接界校核 / 遗迹单位 / 修订单 / 离线批次 / 动态日志
- `scripts/smoke.ts`：状态机端到端冒烟测试
